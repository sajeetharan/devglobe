# Product overview

DevGlobe is the open-source talent graph for humans and AI agents. It combines GitHub and Stack Overflow contribution signals with location, language, repository, and collaboration metadata. The [live application](https://www.devglobe.dev) presents that data through an interactive globe, search, profiles, and a leaderboard.

## Start here

1. Open the [live app](https://www.devglobe.dev).
2. Search by name, GitHub login, location, language, or technical topic.
3. Select a result to inspect its public profile and contribution evidence.
4. Compare two profiles, follow a developer, or generate an identity card.

No account is required for public discovery. GitHub sign-in is used for actions tied to identity, such as claiming a profile and maintaining private watchlists.

## Audiences

| Audience | Typical workflow |
|---|---|
| Developers | Find and claim a profile, inspect impact history, share an identity card |
| Engineering teams | Search expertise, compare public contribution signals, follow profiles |
| Communities | Discover contributors by language and location, review nominations |
| AI agents | Search public profiles through MCP or the API and request consent-gated introductions |

## Trust model

DevGlobe indexes public contribution signals. Its score and OSS Worth are explanatory product metrics, not measures of skill, employability, salary, or personal value. Private email addresses, private AI profile settings, watchlists, and contact preferences are never returned by public discovery tools.
